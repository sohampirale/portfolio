## System Architecture

DockHostV2 bridges web-based developer tooling with backend container infrastructure.

### Core Architecture Components

1. **Control Plane (Next.js & Express)**: Handles user authentication, container scheduling, database state, and routing.
2. **Worker Node Agents**: Lightweight daemons running on worker servers that interact directly with the local Docker daemon socket (`/var/run/docker.sock`).
3. **Interactive Web Terminal**: Streams PTY terminal IO between the web browser and the container's bash session using xterm.js and Socket.io.
