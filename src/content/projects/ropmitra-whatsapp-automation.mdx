## Deep Dive: Low-Footprint Architecture

When building automation tools for local businesses in regional markets like Maharashtra, keeping operational overhead low is paramount. 

Instead of relying on heavyweight cloud queues like BullMQ or Redis, **RopMitra Outreach** uses a custom task scheduler built on top of `better-sqlite3`.

### Key System Features

1. **Transactional Queueing**: Campaign batches uploaded via CSV are parsed, sanitized, and inserted into SQLite inside a single database transaction.
2. **Rate-Limited Dispatcher**: A background worker process polls the SQLite queue every minute, enforcing a strict schedule (1 message / 5 minutes per device session) to prevent account bans.
3. **Marathi PDF Invoicing**: Integrates invoice generation to auto-send formatted PDF receipts over WhatsApp upon order completion.
